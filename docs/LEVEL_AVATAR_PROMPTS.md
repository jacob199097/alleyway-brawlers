# Level profile picture prompts (ChatGPT)

Every 5 levels a player unlocks a new profile picture (`level:5` … `level:50`). Until a picture
exists the game shows that level's emblem instead. Each one matches the title earned at that level.

Paste one prompt per chat message, attaching `assets/cards/card_nebu_001.png` as the style
reference. Save each result as a PNG named `level_05.png`, `level_10.png` … `level_50.png` in
`assets/avatars/`, then run `godot/tools/sync_assets` (or ask Claude to bring them in). They ship in
the next patch.

---
