# Level icon prompts (ChatGPT)

Paste one prompt per chat message into ChatGPT. Download each picture as a PNG and save it as
`assets/levels/chatgpt/level_NN.png` (`level_01.png` … `level_10.png`). Then run:

    godot --headless --path godot --script res://tools/import_level_icons.gd

It removes a leftover solid background, trims and squares each emblem, and writes it to
`assets/levels/level_NN.png` (the game's copy). Levels without a ChatGPT picture keep the drawn ones
from `tools/make_badges.gd`, which skips any level that has one.

If a picture comes back with text or a number on it, or with a scene behind it, reply "Same emblem,
but no text and a plain transparent background" in the same chat.

The frame changes with each title bracket (1-4 scrap steel, 5-9 green neon, 10-14 teal neon …), so
emblems in the same bracket look like a set.
